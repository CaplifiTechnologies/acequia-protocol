## Sovereignty gate

Gates check material compatibility, not identity. Default preserves the position of the person with least leverage. Override is always available to the rights-holder. Three rules: (1) material question only -- never identity, worthiness, or standing; (2) default protects least leverage -- not always open, not always closed, always protective of the individual; (3) override to rights-holder -- not to the operator, vendor, or platform. A gate that can answer "who are you" will eventually be used to answer that instead of "what is this." Sovereignty gate means the gate cannot ask the question. Full spec: specs/SOVEREIGNTY-GATE.md.

## Flows — telos / anti-telos

Five governed flows. One standards body. Each flow has a telos (what it is for) and an anti-telos (what it prevents). Every pitch is the anti-telos stated plainly, then the telos as the answer. The positioning spine holds across all five.

## ORIGAMI fold grammar

The brand is one sheet. Variants are declared folds on that sheet -- never copies that fork it. Each fold opens creases appropriate to its combination of dimensions. The fold manifest names what each variant did NOT see. Analytics selects the Lens; brand disposes.

### Fold dimensions

| Dimension | Creases | What it governs |
| --- | --- | --- |
| **Flow** | supply-chain / community-data / water / labor / ai-governance | Which governed flow the communication addresses |
| **Audience** | city-council / library / law-enforcement / water-district / mining / energy / fabrication / compute / civil / labor / policymaker / general | Whose problem is named |
| **Relationship** | outsider / prospect / parciante / comisionado | How much internal language is appropriate |
| **Channel** | landing-page / paper / email / spec / agreement / presentation | Format and density constraints |
| **Stage** | draft / namespace / founding-table / first-contract / seated | What is true NOW about Ditch AI's status |
| **Tier** | LABEL / HANDLE / FULL | ORIGAMI fidelity -- what detail level is shown |

### Fold rules

1. **Every tier must be true.** A HANDLE pitch that promises something FULL does not support is non-conforming. Folding hides detail, never changes the claim.
2. **Fan-copy bans gate by relationship.** Acequia terms open at `parciante` and above, never below.
3. **Stage gates copy.** At `draft`, never say "the table" as if it is seated. At `namespace`, the specs are migrating. At `founding-table`, recruitment is active. Each stage has claims that are true and claims that are not yet true.
4. **Flow selects telos/anti-telos, not identity.** Ditch AI is one body. All five flows share the positioning spine. What changes: which anti-telos names the reader's problem, which telos names the answer.
5. **Channel constrains density.** A landing page is LABEL + one HANDLE fold. A paper (Headgate Papers) is deep HANDLE. A spec is FULL. An email is HANDLE, scoped to the recipient's flow and audience.
6. **Analytics proposes crease ids; brand disposes.** A weight that asks for a channel-forbidden or stage-forbidden crease is DENY, logged, falls to base figure.
7. **Anti-telos is the opening.** State the problem (anti-telos) before the answer (telos). The reader must recognize their own situation before the table means anything.

### Headgate is a public name

Three products. Draft. Not ratified.

| Name | What it is |
| --- | --- |
| Headgate Standard | The record. Deterministic. No keys. Append-only. The same facts produce the same decision. The line only grows. A key never sits in the record. |
| Frontier Headgate | The API gate. A call stops here before a frontier model runs. |
| Egress Headgate | Every way out. One bench is one egress. The same clamp can sit on a file, a letter, a socket, or a reply. |

The model may ask. It does not open the gate. Unknown stays shut. An act that is not recorded is forbidden.

The fan-copy ban on the word headgate is lifted for these names, on a landing and in a spec. DAC-1, Founding Steward, INSTIGATE, parciante, comisionado, mayordomo, repartimiento, aforo, and Camelot Approve stay off outsider copy.

### Slop

Slop is the flagship olive branch. Its job is to make AI more useful. A Headgate sits on it: the useful path still has a way out that can be shut, and a record that does not hold a key.

### Slopstream

Slopstream is a term to keep. It is Slop in motion. It does not rename Slop, and Slop does not retire it.
